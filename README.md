# AI E2E Regression Suite (Demo Scaffold)

Initial TypeScript project structure for a demo automation framework using:

- Playwright
- Azure OpenAI (mock)
- Jira MCP simulation

## Demo Target

- OrangeHRM demo site: https://opensource-demo.orangehrmlive.com/

## Folder Structure

- `jira/` - Jira MCP simulation module placeholder
- `agent/` - Agent orchestration placeholder
- `healing/` - Self-healing strategy placeholder
- `playwright-tests/` - Playwright test specs placeholder
- `docs/` - Design and runbook documentation placeholder
- `screenshots/` - Test evidence and captured images

## Getting Started (Scaffold Only)

1. Install dependencies
2. Copy `.env.example` to `.env`
3. Run Playwright setup when implementation starts

## Notes

- This repository currently contains structure and configuration only.
- No functional implementation is included yet.
